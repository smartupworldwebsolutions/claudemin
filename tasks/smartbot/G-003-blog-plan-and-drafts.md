# G-003 - Blog plan + first 8 article drafts for SmartBot's public blog (research + bulk writing)

**What it is for:** SmartBot (a subscription website-audit assistant that learns your site) is getting a public blog at its website root /blog. Claude will build the blog pages later; this task is the CONTENT.

**Audience:** small business owners and site owners who are not technical. Plain words, no jargon without a one-line explanation.
**Voice:** plain-spoken, budget-conscious, reassuring, first person plural ("we"). Honest: never claim SmartBot is better than Ahrefs/Semrush (it has no backlink database or keyword volumes). Sell "it gets better at YOUR site". Every number must be real; say what SmartBot does NOT do. Use only facts from context/SMARTBOT_PUBLIC_FACTS.md about SmartBot; do not invent features, prices or statistics.
**No client data:** use made-up example sites only (e.g. "a bakery shop site"). Never real client names or URLs.

**Do this (research the web first for what small site owners actually search for, and cite sources for any outside fact):**
1. A table of 40 blog article ideas: working title, target search phrase, search intent (learn / fix / compare / decide), one-line angle, which SmartBot feature it naturally leads to (or "none - pure help"), priority 1-3.
2. Choose the 8 best (priority 1) and write each as a full draft, 900-1300 words: title, meta description (max 155 chars), H2/H3 structure, short intro, practical steps a non-technical owner can do in WordPress, a short honest "where SmartBot helps" paragraph (not salesy, max 3 sentences), a 3-question FAQ.
3. A list of facts you used from outside SmartBot with their source URLs, so Claude can check them.

**Answer format:** follow GEMINI.md. Send in parts: PART 1 = the 40-idea table + the list of 8 chosen titles; then one part per 2 articles. Save as .md. Start each part with "PART n of N", end with "END OF PART n". Finish with "END OF BRIDGE-ANSWER G-003".
